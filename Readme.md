# AI Code Explainer Tool

## Overview:
AI Code Explainer Tool is a Python-based application that takes user-input code and explains each line,It helps users understand how code works step-by-step.

## Features:
- Explain code line-by-line.  
- Supports basic Python concepts (loops, print, variables, conditions).  
- Beginner-friendly explanations.  
- Continuous interactive mode.  
- Works offline.  

## How to Run:
1. Make sure Python is installed.
2. Open the project folder.
3. Run the file using:

   python_AI_Code_Explainer_Tool.py
